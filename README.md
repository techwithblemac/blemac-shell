# BLEMAC Shell — pygame edition

Pygame-only launcher. No Kivy. Games run in the shell's own window.

Desktop: `pip install pygame-ce` then `python main.py`

Android: push to GitHub — Actions builds the APK (Actions tab -> artifact).
Games folder on phone: /sdcard/BlemacShell/games/<game>/ (game.json + main.py).
Bundled games are copied there on first run.
